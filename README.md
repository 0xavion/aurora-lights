# Aurora Lights (GTA:SA Android)

Animated aurora curtains for GTA: San Andreas on Android, loaded through [Android Mod Loader (AML)](https://github.com/AndroidModLoader/AndroidModLoader). Aurora groups stay at fixed positions across the map, with a new layout each in-game night.

The in-game menu controls colors, movement, softness, regional ambient lighting, and when the aurora appears. Textures are generated by the plugin; no texture pack is needed.

## Requirements

- GTA: San Andreas for Android with AML installed. The code targets v2.00 and v2.10 on ARM32, and v2.10 on ARM64.
- Android 7.0 (API 24) or later, matching the native build target.
- A plugin binary that matches the **game's ABI**, which may differ from the phone's architecture.

| Game ABI              | Release file                     |
| --------------------- | -------------------------------- |
| ARM32 (`armeabi-v7a`) | `libauroralights-armeabi-v7a.so` |
| ARM64 (`arm64-v8a`)   | `libauroralights-arm64-v8a.so`   |

## Installation

1. Download the matching binary from [Releases](https://github.com/0xavion/aurora-lights/releases).
2. Copy it into your AML mods directory. Keep only one Aurora Lights binary installed.
3. Restart GTA and load a game. The plugin creates `AuroraLights.ini` in AML's config directory.
4. Go outdoors at night. The default appearance window is **21:00–05:00**, in all regions and weather.

## Configuration

Tap **Aurora** at the bottom-left of the screen to open the controls. Changes apply live; use **Settings → Save to AuroraLights.ini** to keep them after restarting. For a quick daytime preview, use **Force Aurora NOW (24/7 Test Mode)**.

See the [configuration guide](docs/configuration.md) for every INI key, default, range, menu control, weather ID, and troubleshooting step.
